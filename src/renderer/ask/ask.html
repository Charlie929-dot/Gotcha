    问记忆要把你问的这句话、几段窗口文本（标题 / 命中原文）、提问前最后一段窗口的应用与标题， 和这段对话之前的几轮发给模型。确认一次之后不再打扰。

    供应商
    
            
    
              直接填写 API Key 即可（保存后立即生效）：密钥写入本机 userData/.env，不进设置库、
              不写日志、不回显。同名环境变量存在时以环境变量为准。
            
    
            
            
    
            
          
    

          
    
            
    出网
    
            
            
    
              问记忆会把问题、命中的窗口文本、提问前最后一段窗口的应用与标题，和这段对话之前的
              几轮发给模型；原始截图与完整正文永不离开本机。
            
    
            
            
    
              问记忆与后台归纳共用这一份日额度；今日用量达到上限后不再出网，第二天自动重置。
