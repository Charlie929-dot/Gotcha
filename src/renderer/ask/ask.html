对话

    问记忆要把你问的这句话、几段窗口文本（标题 / 命中原文）、提问前最后一段窗口的应用与标题、 你主动附加的图片 / 文件，和这段对话之前的几轮发给模型；具体发什么取决于顶部模式 （问记忆 / 聊天 / 提问）。新对话的第一问还会带上「此刻」 （当前时间、今天说过几句、上次说话多久前、日记记到哪天）和按你的问题想起的几条日记片段（只是联想）； 开启「看历史截图」后还会带上打开过的段对应截图。确认一次之后不再打扰。

    供应商
    
            
    
              直接填写 API Key 即可（保存后立即生效）：密钥写入本机 userData/.env，不进设置库、
              不写日志、不回显。同名环境变量存在时以环境变量为准。
            
    
            
            
    
            
          
    

          
    
            
    出网
    
            
            
            
    
              问记忆会把问题、命中的窗口文本、提问前最后一段窗口的应用与标题、你主动附加的图片 / 文件，
              和这段对话之前的几轮发给模型。发送内容随顶部模式变：问记忆 = 屏幕记忆 + 日记；聊天 = 人格卡 +
              日记（不翻电脑记录）；提问 = 只有问题和对话。新对话的第一问会多带一段「此刻」（时间、今天说过几句、
              间隔、日记记到哪天）和按问题想起的几条日记片段；开启「看历史截图」后，read_segment 打开的段会附上
              最近一张截图；完整正文不离开本机。启用的人格卡全文也会随聊天提问发给模型。
            
    
            
            
    
              问记忆与后台归纳共用这一份日额度；今日用量达到上限后不再出网，第二天自动重置。
