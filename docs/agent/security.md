# 安全、隐私与权限

> `AGENTS.md` 的外链细节，按需读。

## 三条硬前提

- 采集**默认暂停**，用户显式开启后才开始记录。
- 原始数据（截图/OCR/事件/图谱/归纳）永不离开本机；只有「理解」可脱敏后出云。
- 本项目**默认无遥测、无第三方分析 SDK**。

## 凭据

- `DEEPSEEK_API_KEY` 等用 `.env` / 环境变量；示例配置可提交，真实配置不提交。
- 密钥、token 不进代码、日志、提交、命令参数、截图。

## 三层脱敏墙（出云唯一出口）

1. **正则层**：AK/SK、JWT/Bearer、手机号、身份证、银行卡、邮箱、IP、URL query 参数
2. **结构层**：黑名单进程（密码管理器/网银/隐私窗口）只记元数据；检测到密码输入框 → 整帧丢弃
3. **策略层**：命中记 `sensitive=1`，节点显示「内容已保护」占位

- 所有送云端的文本必须经过**同一个**脱敏函数；禁止业务代码直接 fetch DeepSeek。
- **适用范围**：三层墙覆盖**一切离开采集进程的内容**——OCR 文本、LLM 结构化输入，以及 M4 起的剪贴板/URL 意图信号（命中敏感规则的剪贴板内容不触发提示、不入日志、不留查询文本）。
- 新增敏感规则 = 新增 golden 用例（见 testing.md）。

## 出网

- 仅 DeepSeek（脱敏后）；新增任何外部请求先报备并说明数据内容。
- 出网数据最小化：只发必要字段。

## 破坏性操作

- 删除/覆盖/迁移数据：先确认路径与范围 → 备份（库文件命名 `<库名>.db.bak.<日期>`，库名以 M1 建库定稿为准，暂定 `memory.db`）→ 执行 → 保证可回滚。
- 清空事件/截图/整库前必须得到明确确认。

## 权限与 AV

- 只申请任务所需的最小权限；不关闭校验/沙箱/审批。
- **M1 不上全局键鼠钩子**（AV 误报风险，见 gotchas.md）。

## 对外

- 自用阶段不分发、不推广、不开源；对外发布（含截图/日志分享）先拿到明确授权并脱敏。
