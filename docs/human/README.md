### 三、两份文档共同的缺口（「漏」）

1. **信息链没有出现**：窗口段、`chain_content`、证据截图、标签 / 双链、段向量、检索、问记忆——这是 2026-10-25 之后的主力，两份原稿都写于此前。
2. **出云边界没有出现**：D24 确认门、D22 日账、D19 二次扫描、D49 核心 / 策略分离。
3. **本地向量 / 进程模型过时**：bge-m3 / sqlite-vec / 单进程，实际是 bge-small ONNX + `chain_vector` + 多进程。
4. **性能工作没有出现**：search / embedding 的 `utilityProcess`、大图静态布局、tmp-chain janitor。
5. **个人记忆（另一套系统）**：两份文档都没有；目前未开工，只有方向文档里的概念。
