## 1. 产品定位

一个常驻桌面边缘的「记忆球」，安静地观察你的电脑使用过程，把散落的知识、行为、时间沉淀为一张可以缩放探索的关系图谱，并在你寻找什么的时候，轻轻地提醒你「这个你之前见过」。

**一句话**：它不只是图库，是一本以关系图谱为载体、由 AI 持续维护的「可视化记忆」。

### 1.1 已确认的产品决策（来自前期澄清）

| # | 决策 | 结论 |

## 2. 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│  交互层   悬浮球 · 弱提示脉冲 · 图谱画布 · AI 解说面板 · 设置   │
├─────────────────────────────────────────────────────────────┤
│  图谱层   节点/边+权重 · sigma.js 力导向 · LOD 分层缩放        │
├─────────────────────────────────────────────────────────────┤
│  记忆层   L0 事件流 → L1 知识/行为节点 → L2 日 → L3 周/月 → L4 年   │
├─────────────────────────────────────────────────────────────┤
│  理解层   敏感信息墙 → OCR → DeepSeek 结构化（脱敏后）         │
├─────────────────────────────────────────────────────────────┤
│  采集层   屏幕帧差捕获 · 前台窗口元数据 · 剪贴板/URL 信号       │
├─────────────────────────────────────────────────────────────┤
│  存储层   SQLite（本地唯一事实源）· 截图冷存储（可选）          │
└─────────────────────────────────────────────────────────────┘
```

贯穿式横切：**隐私总开关**（一键暂停/恢复/清除）、**脱敏管道**（出云前的唯一出口）。

## 3. 技术选型

| 层 | 选型 | 理由 | 备选 |
|----|------|------|------|
| 应用外壳 | **Electron + TypeScript** | 透明无边框 always-on-top 窗口成熟稳定；Node 直接调 Win32；前端即图谱画布；nsis 打包一条龙 | Tauri（更轻但 Rust 门槛高、WinRT 封装弱，不选） |
| 屏幕捕获 | `desktopCapturer` + **帧差检测**（dHash） | 内容不变不送下游，功耗与成本双降；只裁前台窗口区域 | screenshot-desktop |
| 窗口元数据 | `active-win`（npm） | 直接拿 title / 进程名 / 应用路径 | koffi 调 GetForegroundWindow |
| OCR | **Windows.Media.Ocr（WinRT 系统 OCR）** | 零依赖、离线免费、中文语言包已随系统 | RapidOCR（onnxruntime，中文精度更高，作二期替换） |
| 云端大脑 | **DeepSeek API** | 已在用；批处理 + 规则前置控制成本；输出严格 JSON | — |
| 存储 | **better-sqlite3** | 同步 API 快；单文件本地；FTS5 全文检索内置 | — |
| 向量检索（二期） | ~~`sqlite-vec` + bge-m3~~ → **自建 `chain_vector`（int16 量化）+ `bge-small-zh-v1.5` ONNX**（本地、随应用分发，D30/D37） | 纯本地、无外部依赖；2026-10-28 已落地 | DeepSeek embedding（有出云成本） |
| 图谱渲染 | **Foam graph-view**（2026-10-23 重做） | Lit + force-graph，源码可改；1 跳邻域、局部图、类型过滤现成；相关度用距离编码 | 原 sigma.js + Graphology + FA2（已归档），见 `docs/m2-graph-redesign.md` |
| 图谱源码参考 | **Foam graph-view**（MIT，源码可改） | 直接 vendor `packages/foam-graph`；force-graph 生态，1 跳邻域/局部图/过滤现成 | Obsidian 闭源，仅作参考 |
| Obsidian 互通（M5） | 导出双链 markdown 到 vault | 与个人 Obsidian vault 工作流合流 | — |

### 3.1 进程模型

> 2026-10-28 实况：不是单进程。当前是 **Electron 主进程 + 隐藏采集 renderer + 长驻 PowerShell UIA worker + `utilityProcess`（embedding / search）+ 图谱 / 问记忆窗口**；OCR 与抓帧在采集链路，重活已陆续搬出主线程。

单 Electron 进程起步（采集调度、IPC、UI 同进程，自用无需拆分），重活（OCR、归纳任务）走 **worker + 本地任务队列**，保证 UI 永不阻塞。二期若上本地模型，再拆 Python sidecar 子进程。

## 4. 数据模型

SQLite 四张核心表（原文曾误记「五张」，2026-10-21 核实为四张：`events` / `nodes` / `edges` / `settings`）；另有若干**派生表**（可重建，不是事实源）：v3 时刻层 `moments` / `theme_moments` / `node_embeddings` / `node_positions`（见 `docs/m2-graph-redesign.md` §4）、v4 `node_merges` / `event_embeddings` / `theme_centroids`、v5 检索索引 `events_fts`（见 `docs/memory-orb-design-proposal.md` §3）。当前 schema 版本 v5。

> **2026-10-28 校正**：主库 schema 已到 **v7**；信息链另有独立记账 **`chain_meta.schema_version = 4`** 与 10 张 `chain_*` 表（`chain_segment` / `chain_event` / `chain_shot` / `chain_content` / `chain_tag` / `chain_link` / `chain_link_segment` / `chain_vector` / `chain_derive` / `chain_meta`）。`nodes` / `edges` 归纳模型已随 D38 冻结；表与不变量以 `docs/information-chain-contract.md` 为准。

```sql
-- L0 原始事件流（精确层，图谱默认折叠）
events(
  id INTEGER PK,
  ts INTEGER,                -- 毫秒时间戳
  app TEXT,                  -- 进程名
  window_title TEXT,
  ocr_text TEXT,             -- OCR 全文
  shot_path TEXT,            -- 截图路径（可关）
  intent_json TEXT,          -- LLM 结构化：在做什么/实体/意图/状态
  sensitive INTEGER DEFAULT 0 -- 1 = 命中脱敏规则；本地保留原文，出云时剥离（D10/D19）
);

-- 图谱节点（L1~L4 一等公民）
nodes(
  id INTEGER PK,
  level INTEGER,             -- 1 知识/行为  2 日  3 周  4 月/年
  type TEXT,                 -- knowledge | activity | daily | weekly | monthly | yearly
  title TEXT,
  summary TEXT,
  ts_start INTEGER, ts_end INTEGER,
  source_events TEXT,        -- 归纳来源的事件 id 列表（可回溯）
  meta_json                  -- 实体、情绪、场景标签等
);

-- 图谱边（带权重）
edges(
  id INTEGER PK,
  src INTEGER, dst INTEGER,
  weight REAL,               -- 0~1，AI 判定 + 行为共现累计
  kind TEXT,                 -- ai | temporal | manual
  evidence TEXT              -- 连边理由（AI 解说时展示）
);

settings(key TEXT PK, value TEXT);   -- 一切自定义项
```

**归纳链路**（AI 统一维护）：
```
events ──(定时/空闲时 AI 归纳)──→ L1 nodes ──→ L2 daily ──→ L3 weekly ──→ L4 monthly/yearly
   └────────── 每层归纳同时产生带权边 ──────────┘
```
- L1 节点由「一批相关事件」聚成：同一搜索会话、同一文档、同一话题
- L2+ 节点由下层节点按时间窗归纳，`source_events` 保证**任何上层节点都能下钻回原始精确记录**

## 5. 核心流程设计

### 5.1 屏幕感知管线（全程后台）

```
隐私总开关：默认暂停 ──(用户显式开启)──→ 启动采集
                                    ↓ (Alt+P 随时切回暂停，管线静默全链路)
每 2s 截图(前台窗口区域, 降采样)
   → dHash 与上一帧比对，未变 → 丢弃
   → 变了：窗口元数据 + OCR
        → 脱敏管道（见 5.4）
        → 入队：每 N 条 / 每 M 分钟批量送 DeepSeek
        → 输出 intent_json 写 events
```
- 规则前置：窗口标题已能说明的（IDE 文件名、文档标题）不调 LLM
- 相似内容合并：连续 N 帧同一主题只算一个「时刻」

### 5.2 主动弱提示（产品灵魂）

**信号源**（按侵入度从低到高）：
1. 剪贴板出现「搜索特征」内容（问题句、术语、报错信息）——**剪贴板信号与 OCR 同样过 5.4 三层脱敏墙**：命中敏感规则则不触发提示、不入日志、不留查询文本
2. 浏览器地址栏/URL 命中搜索引擎
3. 前台窗口标题出现关键词

**动作链**：
```
信号 → 本地图谱检索（FTS5 关键词 + 二期 embedding）
     → 有命中 → 悬浮球微弱收缩一次（呼吸感，不弹窗）
     → 用户点击 → 迷你面板：相关历史节点按权重排序平铺
```
- 自定义：提示强度（呼吸幅度）、频率上限、静默时段（默认 23:00–08:00 静默）
- 设计红线：**永不自动抢焦点**，只等用户主动点

### 5.3 AI 解说面板（点击节点）

| 区块 | 内容 | 开关 |
|------|------|------|
| 记录 | 时间、持续时长 | 常驻 |
| 场景 | 来自 L0 事件的忠实还原（应用、窗口、OCR 摘要） | 可关 |
| 详情 | L1 节点的知识/行为叙述 | 可关 |
| 推理 | LLM 基于跨时间记忆的评价：「你最近一周密集查 X，像是在准备 Y」 | 可关 |
| 建议 | 下一步行动建议、关联旧节点推荐 | 可关 |

### 5.4 脱敏管道（云端唯一出口）

三层过滤，全部在**出云前**执行，原文永不离开本机：

1. **正则层**：AK/SK、JWT/Bearer token、配置/JSON 凭据赋值（含带引号键名）、手机号、身份证、银行卡、邮箱、IP、URL query 参数
2. **结构层**：黑名单进程（密码管理器、网银、隐私窗口）→ 只记元数据不记内容；检测到密码输入框 → 该帧整体丢弃
3. **策略层**：脱敏命中记 `sensitive=1`，图谱节点显示「内容已保护」占位

> **2026-10-28 补**：三层墙只在**离开设备**时强制生效。真实出云还要过 **D24 一次性确认 + D22 日账 + D49 边界策略**；问记忆 / 派生层的协议组装在核心，脱敏策略在 `understand/cloud/*-outbound.ts`，核心不 import 脱敏实现（`docs/agent/cloud-boundary.md`）。

> 二期本地模型路线：整套管线不变，仅把「理解层」从 DeepSeek 换成本地 LLM，存储与图谱零改动——这是架构上有意留的替换点。

## 6. UI / 交互设计

### 6.1 悬浮球状态机

```
收起态 ──(悬停/拖拽)──→ 展开态
  │                        │
  ├──(图谱命中信号)──→ 脉冲态（微弱收缩一次，幅度随强度设置）
                           └──(点击)──→ 图谱/迷你面板
  └──(隐私暂停 / 默认未开启)──→ 暂停态（可区分的视觉形态：灰暗 + 斜杠图标）
```
- 暂停态约束：悬浮球任何时刻都可见「当前是否在记录」——暂停与运行在视觉上不可混淆，这是信任的物理基础
- 贴边自动半透明，滚轮可临时唤出
- 全局热键：`Alt+Space` 展开图谱，`Alt+P` 隐私暂停（自用救命键）

### 6.2 图谱画布

> 2026-10-23 图谱重做：本节「线宽 + 布局距离双重编码」与 sigma.js 选型已归档，新方案见 `docs/m2-graph-redesign.md`（本地向量相似度 + 仅距离编码 + Foam 画布）。

- **视觉编码**：知识节点 / 行为节点 / 日 / 周 / 月 / 年，六类六色，层级越高越亮越大（深色底上的递进明度，而非「越暖」）。暂定色板（M2 落地时可调）：知识 `#4FC3F7` · 行为 `#81C784` · 日 `#BA68C8` · 周 `#F06292` · 月 `#FFB74D` · 年 `#FFF176`
- **相关性编码（2026-10-23 变更）**：连线由本地 bge-small 向量相似度生成，**只用布局距离**编码相关度；线宽统一，不再编码。旧「边粗细 + 布局距离双重编码」已归档，见 `docs/m2-graph-redesign.md`。
- **LOD 缩放**：默认视图看到「极度相关」的强连接子图；缩小 → 中弱连接浮现；缩到最小 → 只见月/年记大节点（中心簇 + 辐射小点，正是缩放 LOD 的自然形态；策划案 §8.2 引用本条为 LOD 语义唯一来源）
- **交互**：悬停高亮邻域、点击开解说面板、滚轮缩放、拖拽平移、框选局部、时间轴筛选（只看某周）

### 6.3 设置项（全部本地 settings 表）

截图频率 · OCR 开关 · LLM 批处理窗口 · 提示强度/频率/静默时段（默认值以 testing.md §用例纪律 的 23:00–08:00 为单一来源，此处不另定）· 解说服务五项开关 · 黑名单应用 · 数据保留期 · 隐私暂停。

## 7. 实施路线（MVP 驱动，每阶段可独立验收）

| 里程碑 | 周期 | 内容 | 验收标准 |
|--------|------|------|----------|
| **M1a 采集存储底座** | 1–1.5 周 | 帧差截图 + OCR + 窗口元数据 + SQLite 事件流 + 时间线只读视图 | 能回答「我昨天下午三点在干嘛」，精确到窗口和 OCR 摘要 |
| **M1b 悬浮球壳** | 1–1.5 周 | 悬浮球（收起/悬停/拖动/暂停态视觉）+ 隐私总开关接线 | 球可常驻贴边，暂停/运行状态视觉可辨；Alt+P 全链路生效 |
| **M2 知识行为图谱** | 2–3 周 | ~~sigma.js~~ → Foam 画布（2026-10-23 重做；2026-10-25 冻结，D38） | 图谱上能看到一天内的知识点与行为连线，可缩放平移 |
| **M3 分层记忆** | 2 周 | 日/周/月归纳队列 + 权重边 + LOD 缩放 + 下钻回溯 | 缩到最小时只见月记级大节点簇；点开能下钻到原始事件 |
| **M4 主动与解说** | 1–2 周 | 剪贴板/URL 信号检索 + 弱提示脉冲 + 解说面板五区块 + 自定义开关 | 搜索某话题时球会脉冲，点开有相关历史；解说可只留「记录」 |
| **M5 打磨合流** | 持续 | Obsidian 双链导出、性能优化（万节点）、隐私模式细节、打包分发 | 图谱数据可导出双链 md 进 vault（**深度待拍板**：单向导出 or 双向同步，拍板前只承诺单向）；隐私模式一键静默全链路 |

**顺序逻辑**：M1a/M1b 先解决「感知与存证 + 信任可见」，M2 让数据可见，M3 兑现「分层记忆」这个最核心的产品差异点，M4 才上主动智能——**没有 M1–M3 的积累，M4 的提示就是无米之炊**。

> 2026-10-28 实际：M1a/M1b ✅；M2 🧊 冻结；当前在信息链（段 / 内容 / 证据图 / 双链 / 检索 / 问记忆）与性能、本地向量；M3/M4 未开工。

### 7.1 成本模型（M2 起实测校准，本节数字为待验证的量级估算）

M2 上线 DeepSeek 结构化后需有账可算：**每日有效事件数（帧差后）→ 批处理次数 → 每次 token 数 → 日/月成本**。量级参考（推测，M1a 实测后回写）：

- 8h 使用 / 2s 采样 = 14400 帧/天；帧差 + 静默丢弃后估 **500–2000 有效帧/天**
- 规则前置过滤（标题可解释的不调 LLM）再砍 30–60% → **约 300–1000 条/天送 LLM**
- 按批处理每批 20 条、每批约 8k token 估：**日成本控制在个位数元级**；超预算触发降频（拉长批窗口、提高规则前置阈值）

> 阈值写进 settings 表，M1a 埋点统计有效帧率，M2 第一次校准本节。
